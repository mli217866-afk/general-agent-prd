## 1. 产品概述

### 1.1 一句话定义

Agent 是一台装在用户自己电脑上的通用 AI 工作体：以可对话的智能体为核心，配备文件、终端、浏览器、互联网、媒体生成、办公文档和协作平台等能力，在用户授权边界内自主完成多步骤工作，并全程可观察、可拦截、可回放。

### 1.2 问题定义

| 现状缺陷 | 用户痛点 | Agent 的回答 |
| --- | --- | --- |
| 网页聊天框无法访问本地环境 | 无法整理本地文件或操作开发环境 | 本地常驻，文件、终端、浏览器原生可达 |
| 大厂客户端强制账号、订阅且过程黑箱 | 数据归属和实际动作不透明 | 无账号、BYOK、本地存储、动作透明 |
| 能力被产品方裁剪 | 无法连接飞书或媒体生成等实际工作流 | 内置全域工具 + Skill + MCP，用户决定边界 |

### 1.3 目标用户与场景

| 用户 | 核心场景 | 关键能力 |
| --- | --- | --- |
| 知识工作者 | 将会议纪要整理成待办并写入任务清单 | 飞书、文档、记忆 |
| 开发者 | 重构模块、运行测试、发起 PR | 文件、终端、代码评审 |
| 内容创作者 | 按脚本生成短视频素材并配音 | 媒体生成 |
| 研究者 | 调研赛道并输出带引用的报告 | Web、深度研究、文档生成 |
| 自动化爱好者 | 定时汇总收件箱和日程 | Cron、定时任务、多会话 |
| 移动办公者 | 通过 IM 派活并批准文件修改 | IM、远程控制 |

### 1.4 产品形态

- macOS / Windows Electron 桌面应用，采用三栏工作台。
- 本地常驻运行时负责会话、任务、调度和存储。
- 桌面为主入口；IM 和手机伴侣端是 P1/P2 扩展入口。
- 所有数据落本地，模型和外部服务由用户配置。

## 2. 产品原则

1. **本地优先**：对话、记忆、任务、凭据默认存于 `~/.jump/`，不提供云端同步。
2. **无账号**：没有注册、登录、SSO、订阅；唯一门槛是用户自己的模型 Key。
3. **能力透明**：工具装配、隐藏项及原因随时可查，能力清单由注册表生成。
4. **动作可拦**：写文件、发消息、外发数据等动作默认需批准，执行必留痕。
5. **失败诚实**：网络、配额和工具异常显式呈现，不白屏、不吞错、不假装成功。
6. **开放扩展**：通过 Tool、Skill、MCP 扩展，不锁定供应商。
7. **重启不发存货**：重启只恢复队列状态，续发必须由新输入或显式恢复触发。

## 3. 总体架构

```text
桌面壳（Electron）
  三栏工作台 / 设置 / 权限弹窗 / 安装更新
        │ preload 白名单
Agent 运行时（本地常驻）
  会话 / Turn / 队列 / Cron / 权限 / 上下文 / 记忆 / 技能 / 事件
        │
Agent 内核                    模型层（多供应商 BYOK）
  循环 / 工具 / 事件流         OpenAI 兼容 / Anthropic / Google / 自定义
        │
能力域
  文件 / 终端 / Web / 浏览器 / 媒体 / 文档 / 飞书 / 部署 / MCP
```

分层约束：UI 进程无 Node 权限；循环协议复用成熟内核，会话、存储和调度为自研资产；能力域只能通过工具协议接入运行时。

## 4. 核心对象

| 对象 | 定义 | 关键属性 |
| --- | --- | --- |
| Agent | 人格与能力天花板的组合 | persona、工具白名单、技能、模型偏好 |
| Session | 持续的工作上下文 | ID、工作区、JSONL 历史、状态、分支 |
| Turn | 一次输入触发的完整运行 | 事件流、工具调用、token、终止原因 |
| Task | 父会话派给子会话的工作单元 | 父子关系、进度、输出、状态 |
| Skill | 按需加载的操作手册 | 名称、描述、触发条件、正文 |
| Goal | 跨多轮目标及预算 | objective、token_budget、状态机 |
| Cron | 按时间表启动的会话 | schedule、prompt、活跃时段、绑定会话 |
| Memory | 跨会话持久知识 | 层、内容、来源 |
| Project | 工作区目录对象 | 归一化路径、置顶、隐藏、排序、最近活动 |

工作区与 Session 松耦合：换工作区或删除 Project 都不删除会话历史。

## 5. 功能需求

优先级：P0 为首个公开版本必须；P1 为首版本力争；P2 为路线图能力。

### FR1 对话与循环引擎（P0）

- 文本逐 token 流式呈现，模型支持时可折叠显示思考过程。
- 支持多轮工具循环、运行中 steering、忙时 follow-up 排队和随时中止。
- 工具默认并行；写类和交互类工具串行。
- 模型级错误终止当前轮并显式呈现。
- P1：图片统一转安全 JPEG 并受体积预算约束；坏图不拖垮整轮，不支持图片的模型降级为纯文本并说明。

### FR2 工具系统（P0 框架）

每个工具必须声明名称、标签、描述、参数 schema、实现、执行模式和权限类别。每轮工具集按“角色天花板 × 模型能力 × 上下文预算”装配，结果和隐藏原因可查。

| 域 | 工具 | 级别 |
| --- | --- | --- |
| 文件 | `read/write/edit/grep/glob` | P0 |
| 终端 | `bash`，支持前后台和进程树超时终止 | P0 |
| 计划 | `todowrite` | P0 |
| Web | `web_fetch` / `web_search` | P0 / P1 |
| 交互 | `ask_user` / `request_feature_enable` | P0 / P1 |
| 编排 | `task/task_append/task_query/task_output/task_stop` | P1 |
| 记忆与技能 | `memory` / `skill` | P1 |
| 代码与自治 | `code_review` / `jump` | P1 |
| 目标 | `create_goal/update_goal/get_goal` | P2 |
| 浏览器 | `browser` 与导航、点击、输入、DOM、截图等 14 个子命令 | P1 |
| 桌面 | `desktop_*` | P2 |
| 媒体 | 图像、视频、音频共 15 个生成与理解工具 | P2 |
| MCP 元工具 | `tool_search/mcp_invoke` | P1 |

子会话禁用委派工具、`todowrite` 和 `ask_user`；内置子代理额外禁用 `jump`，防止套娃与权限穿透。

### FR3 权限与安全（P0）

| 动作 | 默认策略 |
| --- | --- |
| 文件读取、搜索、网页读取、浏览器只读 | 静默执行 |
| 文件写入、编辑、浏览器写操作 | 展示 diff，批准后执行 |
| 终端修改文件 | 权限门 |
| 上传、发消息、部署等联网外发 | 权限门，可按域缓存 |
| `.env`、`.ssh`、云凭据 | 每次弹框，不缓存 |
| 不可逆删除、格式化、截断、secure erase | 永远拒绝，引导到可恢复的回收站通道 |

裁决顺序为静态规则闸 → P1 安全审查模型闸 → 用户闸。用户授权永不覆盖不可逆删除和密钥外发。这里是策略约束与审计留痕，不宣称操作系统级物理隔离。

### FR4 会话管理（P0）

- 多会话独立并行；会话内队列状态为 `queued → claimed`。
- 重启恢复列表、历史和排队状态，但不自动续发。
- P2 支持从历史节点 Fork；标题、归档和删除受生命周期管理。
- 删除顺序固定：封新操作 → 静默队列 → 中止活动轮 → 删除 Turn 事实 → 删除消息、资产、历史、用量 → 删除会话记录；失败可重试。

### FR5 上下文管理（P0）

- 显示 token 占用与模型窗口。
- 按模型窗口、单轮上限、摘要预留和安全边际触发串行压缩。
- 上下文溢出后自动压缩并重试一次。
- 系统提醒不参与压缩；P1 支持摘要链式传递。

### FR6 多智能体编排（P1）

| 角色 | 定位 | 约束 |
| --- | --- | --- |
| root | 理解、拆解、调度 | 全量工具 |
| explore | 只读侦察 | 禁写、禁终端 |
| worker | 范围明确的生产执行 | 收窄写集，只动指定文件 |
| verifier | 交付后独立核验 | 只读报告，不修改 |

子会话拥有独立上下文，通过任务工具与父会话通信；父不轮询，完成事件主动唤醒父会话。

### FR7 目标与预算（P2）

- 仅在用户或系统明确要求时创建 Goal；未完成目标存在时拒绝新建。
- token 预算耗尽后进入 `budget_limited` 并注入收尾指令。
- 仅在真正完成时标记 `complete`；同一阻塞连续三轮后才可标记 `blocked`。
- 未完成目标可自动续跑；过期、暂停、完成或被替换的续跑项自动取消。

### FR8 Cron（P2）

支持 create、list、get、update、delete、trigger、sessions；配置 schedule、prompt、agent、活跃时段和会话复用。Cron 层负责忙时排队，投递到会话后遵循 steering 语义。

### FR9 记忆系统（P1）

| 层 | 范围 | 写入主体 |
| --- | --- | --- |
| user | 跨项目、跨会话 | 用户明确陈述或修正 |
| project | 单项目 | 用户或经批准的智能体 |
| summary | 单会话 | 会话压缩产物 |
| topic | 主题域 | 智能体发现的稳定模式 |

支持 read、search、append、edit、create、delete、write。默认不写、写前搜索去重、选择最窄范围，用户陈述优先于推断，禁止跨用户共享。

### FR10 技能系统（P1）

- `skill({name})` 按需加载完整 `SKILL.md`，不预加载、不常驻。
- 来源为产品内置、工作区 `.skills/`、用户全局目录三级。
- 内置覆盖规划、评审、研究、视觉页面、插件/技能创建、Agent 创建、桌面控制、办公文档、飞书和链接读取等能力。
- 技能以 name、双语 description 和正文操作手册组成。

### FR11 浏览器自动化（P1）

覆盖导航、点击、输入、按键、滚动、悬停、等待、DOM、截图、粘贴、文本校验和可编辑目标检查；支持无头/有头切换，新域名首次导航走权限门。

### FR12 媒体生成（P2）

统一 schema 接入可插拔 BYOK 供应商，覆盖图像、视频、TTS、音乐、转写与多媒体理解。长任务后台执行，完成后提醒，产物落入工作区并可预览。

### FR13 文档处理（P2）

以 Skill 承载 PPTX、DOCX、XLSX、PDF 的读取、创建与编辑；PDF 额外支持 OCR 和 LaTeX 渲染。

### FR14 飞书生态（P1）

以公开 `lark-cli` 为底座，用户自行授权，凭据存于本机。飞书链接按 docx/wiki、sheets、base 等路径自动路由到对应能力，不通过网页抓取；遇授权失败时引导用户完成官方授权。

### FR15 Web 能力（P0/P1）

`web_fetch` 将 URL 转为 Markdown并支持图片/PDF 下载；`web_search` 使用 BYOK 搜索 API 并保留引用源；P2 增加反爬社交链接专用读取。

### FR16 MCP（P1 框架）

- 接入任意标准 MCP Server。
- 工具过多时通过 `tool_search` 和 `mcp_invoke` 延迟披露。
- 设置页展示内联与延迟披露结果。
- 已有官方 CLI 的生态不重复建设 MCP 路线。

### FR17 部署与站点（P2）

支持静态站点一键公开部署；云平台能力以 Skill 指导模型完成交付链路。

### FR18 模型管理（P0）

- BYOK 支持 OpenAI 兼容、Anthropic、Google、Bedrock、Mistral、Azure 等 API 类型。
- 自定义 provider 可配置 base URL、Key、模型清单和兼容开关。
- Key 优先级：运行时覆盖 > 本地凭据 > 环境变量。
- 会话中可无缝切换供应商；完整 Key 永不回显且只存本地。

### FR19 用户交互组件（P0）

`ask_user` 提供多步骤结构化问卷，每步 2–4 个互斥选项，可带图片、推荐标记和开放输入。未答问卷会挂起整个队列；问卷可被取代或关闭。权限框展示 diff、目标路径或域名；工具卡展示参数、结果和耗时。

### FR20 观测与回放（P1）

- 每会话以 JSONL 保存消息、工具、事件和 token。
- 支持时间线回放。
- 区分物理请求、逻辑调用和重试事件。
- 瞬时传输错误指数退避；鉴权、配额和内容策略错误不重试。
- `jump-doctor` 提供日志、根因模式和会话体检。

### FR21 IM 入站（P1/P2）

飞书和 Telegram 为 P1，微信为 P2。账号绑定本地会话，入站消息进入标准会话队列；处理期间展示 typing，终态回投最终结果。权限通过远程控制或 IM 卡片批准，未批准则超时拒绝。

### FR22 手机伴侣端（P2）

镜像会话、队列、权限、问卷、目标等事件，并允许等效远程批复。桌面查询接口是权威状态源；无账号配对采用本地配对码或局域网发现和端到端加密，凭据可吊销。

### FR23 内容安全（P1）

输入审核与首次模型调用并发；拒绝时整轮回撤。审核服务不可用时 fail-closed，API 降级时放行并标记。输出先审后发，可在预算内重新生成，标题也经过同一管线。

### FR24 会话变更集（P1）

自动记录会话内文件变更和归属轮次，右栏展示累计文件及 diff；支持按文件或整会话回滚与重放，回滚本身也写入审计日志。

### FR25 项目目录（P1）

Project 等于归一化工作区目录；支持最近活动排序、会话预览、置顶、隐藏和手动排序。Git worktree 折叠到父仓库。切换项目即切换默认工作区，但删除项目不删除会话。

## 6. 行为契约

### 6.1 工作模式

| 模式 | 契约 | 触发 |
| --- | --- | --- |
| Craft | 读类静默；写类展示 diff；终端和外发走权限门 | 默认候选，待决策 |
| Plan | 不写、不外发，只输出步骤、文件和风险；确认后转 Craft | 用户要求先规划或加载规划技能 |
| Ask | 不调用工具，只对话 | 用户要求只回答、不动文件 |

统一验收指令“整理 todo.txt”：Craft 应读取、展示 diff、批准后写入；Plan 只输出计划；Ask 只给文字建议。

### 6.2 排队与并发

会话内按序排队，多会话独立并行；子任务在后台执行并用完成事件唤醒父会话；Cron 有独立忙队列；重启只恢复不续发。

### 6.3 终止语义

用户中止时停止模型流并让当前工具批次收尾；错误终止整轮并展示错误；预算终止先注入收尾指令再停止。

## 7. 数据与存储

| 数据 | 位置 | 格式 |
| --- | --- | --- |
| 会话历史 | `~/.jump/sessions/` | JSONL |
| 队列、索引、Cron、Goal | `~/.jump/state.db` | SQLite |
| 凭据 | `~/.jump/credentials`，可选 OS 钥匙串 | 加密 JSON |
| 记忆 | `~/.jump/memory/` + 工作区 `AGENTS.md` | Markdown |
| 技能 | 内置 + `.skills/` + `~/.jump/skills/` | SKILL.md |
| 工作区 | 用户指定目录 | 与会话松耦合 |

删除会话即删除 JSONL；归档可恢复；凭据支持单独删除。

## 8. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 启动 | 冷启动 3 秒内显示主界面；运行时基线内存不超过 300 MB |
| 稳定 | 单工具崩溃不拖垮会话；断流重试；UI 有错误兜底页 |
| 安全 | UI 无 Node 权限；凭据不出本机；高敏感路径每次批准；决策留痕 |
| 隐私 | 不上传用户内容遥测；崩溃报告可选且脱敏 |
| 扩展 | 新 Tool、Skill、MCP 不修改核心；角色能力纯配置 |
| 兼容 | macOS 12+、Windows 10+；模型 API 类型可扩展 |

## 9. 发布验收

完整可执行清单见 [RELEASE-GATE.md](RELEASE-GATE.md)。发布必须满足无账号、Key 不回显、权限边界、三档模式、会话恢复、压缩、多模型切换、错误显影、回放、问卷、子任务和干净机器安装等要求。

## 10. 路线图

| 阶段 | 范围 | 出口标准 |
| --- | --- | --- |
| M1 对话底座 | FR1/2 核心、FR3/4/18/19、三栏 UI | 发布门禁 1–7 |
| M2 可靠与编排 | FR5/6/9/10/15/20 | 发布门禁全量 |
| M3 能力全域 | FR11/14/16、语义搜索、Cron、Goal | 能力域演示矩阵 |
| M4 媒体与交付 | FR12/13/17、Fork、桌面自动化 | 安装包公开分发 |

## 11. 明确不做

- 登录、注册、SSO、订阅付费。
- 多人实时协作、云同步、云托管会话。
- 移动端主应用、浏览器插件。
- 自研或微调基础模型。
- 跨用户记忆共享。
- 绕过权限门的全自动模式。
- 隐藏工具装配策略。

## 附录 A：术语

| 术语 | 定义 |
| --- | --- |
| Turn | 一次用户输入触发的完整运行 |
| steering / follow-up | 运行中插话 / 当前轮结束后的排队指令 |
| Assembly | 每轮决定可用工具集的三因子计算 |
| 能力天花板 | 角色允许的最大 Tool 与 Skill 集合 |
| 延迟披露 | MCP 工具按需检索而非预注入 |
| fail-closed | 出错即整体终止，不留部分完成状态 |
| 整轮回撤 | 撤回该轮用户消息和助手输出 |
