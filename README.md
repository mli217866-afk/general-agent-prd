## 可运行 Demo

仓库包含一个浏览器可运行的高保真 Agent 工作台 Demo，用于体验 PRD 中的核心交互契约。

```bash
npm install
npm run dev
```

当前 Demo 包含：

- 三栏工作台、会话新建与切换
- Craft、Plan、Ask 三种模式
- 消息提交、运行状态和工具调用时间线
- 写入操作的批准、拒绝与明确终态
- localStorage 本地状态持久化
- 桌面与窄屏响应式布局

这是产品交互 Demo。模型回复、文件操作和终端执行均为可识别的模拟行为，不会收集 API Key，也不会修改真实文件。真实模型、Electron 主进程和工具运行时属于下一阶段。

验证命令：

```bash
npm test
npm run typecheck
npm run build
```

## 产品定位

通用 Agent 是运行在用户自己电脑上的 AI 工作体。它以对话式智能体为核心，连接文件、终端、浏览器、互联网、媒体生成、办公文档和协作平台，在用户授权边界内完成多步骤工作，并保证过程可观察、可拦截、可回放。本需求文档不绑定具体产品名称、模型厂商或协作平台，可作为同类桌面 Agent 产品的基础规格。

## 核心原则

1. 本地优先：对话、记忆、任务和凭据默认只存本机。
2. 无账号：不提供注册、登录、SSO 或订阅体系，用户自带模型 Key。
3. 能力透明：每轮工具装配结果及隐藏原因可查。
4. 动作可拦：写入、外发等改变外部世界的动作默认需要批准。
5. 失败诚实：错误显式呈现，不吞错、不假装成功。
6. 开放扩展：通过 Tool、Skill、MCP 三种标准接口扩展。
7. 重启不发存货：恢复队列状态，但不自动发送重启前排队的消息。

## 首版范围

首版以桌面工作台、对话循环、文件与终端、权限门、会话恢复、多模型 BYOK 为 P0；上下文压缩、多智能体、记忆、技能、浏览器、协作平台、MCP 和可观测性按 P1 推进；Goal、Cron、媒体、文档、部署、远程控制等进入后续路线图。
